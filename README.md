# Student Portal

## 📖 Overview
The Student Portal is a lightweight web application designed to manage and display student academic records. It allows students to view their results and performance data in a user-friendly interface.

## 🚀 Features
- Student login and result access
- Display of academic performance
- Responsive design with HTML & CSS
- Easy deployment via GitHub Pages

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript
