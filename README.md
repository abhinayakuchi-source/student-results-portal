# 🎓 Student Registration & Result Portal

A responsive **Student Registration & Result Portal** built using HTML5, CSS3, Bootstrap 5, and JavaScript.

## ✨ Features

* Student registration form
* Personal and academic details
* Subject marks input
* Automatic total marks calculation
* Automatic percentage calculation
* Pass/Fail result
* Form validation
* Dynamic result display
* Responsive design for desktop, tablet, and mobile
* Bootstrap components and responsive layout

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* JavaScript

## 📂 Project Structure

student-registration-portal/
│
├── index.html
├── style.css
├── script.js
└── README.md


## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enter the student details and marks.
5. Click **Calculate Result** to view the result.
